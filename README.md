# ezzi | Landing page

Site estático (HTML, CSS e JS puros) da ezzi, com lojas em Arapiraca e Lagoa da Canoa/AL.

Na Vercel, o build `node scripts/build.mjs` gera a pasta `dist/` e troca o marcador
`https://TROCAR-PELO-LINK-DO-VERCEL.vercel.app` pelo link de produção, para a capa do link (`og-image.jpg`) aparecer no WhatsApp e nas redes.
